Connexion à Netlify

Saisissez le jeton d'accès Netlify et l'adresse de votre site pour accéder à la galerie.

Où trouver ces informations ?

Jeton : Netlify → icône du profil → User settings → Applications → Personal access tokens → New access token (il ne s'affiche qu'une fois).

Site : l'adresse du site (nom-du-site.netlify.app) ou le Project ID de Site configuration.
